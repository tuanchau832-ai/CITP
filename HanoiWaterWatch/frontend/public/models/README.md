# Station model upload

Place the user-supplied binary glTF asset here as `station-v1.glb`.
Match node names in `shared/registry`: sensor_ph, sensor_do, sensor_turbidity, sensor_temp, beacon, led_green, led_yellow and led_red. Node positions and geometry must be validated with the supplied asset.

Until the file exists, the application shows its accessible, explicitly illustrative 2D station schematic. No substitute GLB is included.
